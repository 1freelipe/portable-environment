# portable-environment
Node + VsCode + Git em um ambiente portável.

### O repositório conta com markdowns inclusos, explicando exatamente o passo a passo para montar o ambiente portável. Em cada um deles, conta com: O que fazer, como fazer e, por onde baixar.

### Essencial em ambientes restritos:
1. Falta de privilégios administrativos
2. Cenários Educacionais
3. Laboratórios Pessoais
4. Máquinas coporativas gerenciadas

### Vale ressaltar que o guia utiliza versões oficiais, modo portable documentado, não burla segurança, não quebra políticas, não mexe em registro, não desativa antivirus. É apenas para fins educacionais e a curiosidade de criar um ambiente completamente portável sem a necessidade de privilégios administrativos.

## O que você precisa?
- Node.js + npm (Portable)
- Git (Portable)
- VS Code (Portable Mode)
- Sem permissões administrativas
- Sem configurações de sistema

## Qual o público alvo?
- Ambientes corporativos e restritivos
- Computadores gerenciados
- Estudantes sem acesso administrativo

## Principais passos
1. Baixe os arquivos e versões portáveis oficiais de sites oficinais (Node, VSCode, Git)
2. Monte a estrutura de pastas correspondentes
3. Salve os arquivos em suas respectivas pastas
4. Monte o script exatamente como identificado no repositório
5. Realize os testes via terminal quando terminar as configurações. node -v, git --version e npm -v - Se todos eles responderem de acordo com o nome da pasta, está ok!
