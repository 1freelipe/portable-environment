# portable-environment
Node + VsCode + Git em um ambiente portável.

### Essencial em ambientes restritos:

1. Falta de privilégios administrativos
2. Cenários Educacionais
3. Laboratórios Pessoais
4. Máquinas coporativas gerenciadas

### Vale ressaltar que o guia utiliza versões oficiais, modo portable documentado, não burla segurança, não quebra políticas, não mexe em registro, não desativa antivirus. É apenas para fins educacionais e a curiosidade de criar um ambiente completamente portável sem a necessidade de privilégios administrativos.
