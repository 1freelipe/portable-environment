# Node.js (Portable)

## Download
Realize o download no site oficial - Windows Binary (.zip)
(https://nodejs.org)

## Escolha
- LTS Version
- Windows Binary (.zip)
- x64 ou x86 (De acordo com o seu sistema operacional)

## Setup
1. Extraia os arquivos em: C:\<user>\dev-portable\node - Ou de acordo com a criação de pastas no seu sistema.
2. Não execute instaladores
3. Não adicione nada no PATH

## Validação
Abra o CMD na pasta onde o Node foi extraído, ou navegue até a pasta e execute: node -v npm -v
Se retornarem suas respectivas versões, está tudo certo!
