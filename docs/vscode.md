# VS Code (Portable Mode)

## Download
Realize o download .zip no próprio site oficial de distribuição - https://code.visualstudio.com

Escolha: 
- ZIP
- x64 ou x86, de acordo com o seu sistema operacional

## Setup
1. Extraia para: dev-portable\vscode (Ou de acordo com a sua estrutura de pastas)
2. Crie um pasta `data` dentro da \vscode - Isso irá habilitar o modo portátil e os arquivos necessário serão salvos nessa pasta e não em diretórios do sistema

## Notas
- As extensões e as configurações agora são locais
- Sem integração sistêmica
